## Первый вход

После установки откройте `/admin` и войдите под учётной записью Filament-пользователя. Вы попадёте на дашборд панели — пустую страницу с приветствием.

## Главные концепции

### Resources

**Resource** — CRUD-интерфейс для Eloquent-модели. Из коробки Filament генерирует три страницы:

- **List** — таблица всех записей с пагинацией
- **Create** — форма создания новой записи
- **Edit** — форма редактирования существующей

Можно добавить **View** — read-only страницу просмотра.

Каждый Resource автоматически регистрирует пункт в боковом меню.

### Widgets

Виджеты отображаются на дашборде и на страницах ресурсов:

- **Stats Overview** — карточки с числовыми показателями
- **Chart** — графики (line, bar, pie)

### Navigation

Боковое меню формируется автоматически из зарегистрированных Resources и кастомных страниц. Поддерживаются:
- Группировка пунктов (Navigation Groups)
- Кластеры (Clusters) — объединение нескольких ресурсов в один пункт меню
- Кастомные страницы в навигации
- Пользовательское меню (User Menu)

## Создание первого Resource

```bash
php artisan make:filament-resource Post
```

Команда создаёт структуру:

```
app/Filament/Resources/
└── PostResource/
    ├── PostResource.php       # Главный класс ресурса
    └── Pages/
        ├── CreatePost.php     # Страница создания
        ├── EditPost.php       # Страница редактирования
        └── ListPosts.php      # Страница списка
```

После создания ресурс `Post` появляется в боковом меню и доступен для работы.

### Флаги генерации

| Флаг | Назначение |
|---|---|
| `--simple` | Модальные окна вместо отдельных страниц |
| `--generate` | Автогенерация форм и таблиц на основе колонок БД |
| `--soft-deletes` | Поддержка Soft Deletes (restore, force-delete) |
| `--view` | Добавить View-страницу |
| `--model-namespace` | Кастомный namespace модели |

## Навигация по панели

После создания ресурса:
- Ссылка **Posts** появляется в боковом меню
- `/admin/posts` — список записей (List)
- `/admin/posts/create` — создание записи
- `/admin/posts/{record}/edit` — редактирование

## Формы и таблицы

Form Builder и Table Builder — два столпа Filament, вокруг которых строится вся работа с данными. Подробно они рассматриваются в соответствующих разделах:

- **Формы**: декларативное описание полей, валидация, условная видимость
- **Таблицы**: колонки, сортировка, фильтрация, поиск, actions в строках
